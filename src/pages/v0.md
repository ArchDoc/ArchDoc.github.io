# v0 docs (archived)

The v0 viewer (`@archdoc/archdoc-ui`) and its v1.0 specification are no longer maintained. Their docs are archived on GitHub, as they were last published:

- [The v0 viewer](https://github.com/ArchDoc/ArchDoc.github.io/tree/a36b5e632ca56edfc768adaa671d0cfdb2729fc7/versioned_docs/version-1.0.0/archdoc-ui)
- [The v1.0 specification](https://github.com/ArchDoc/ArchDoc.github.io/tree/a36b5e632ca56edfc768adaa671d0cfdb2729fc7/versioned_docs/version-1.0.0/specification)

The viewer's code is frozen at [`v0.2.0`](https://github.com/ArchDoc/archdoc/releases/tag/v0.2.0) on the [`legacy/v0`](https://github.com/ArchDoc/archdoc/tree/legacy/v0) branch.

To move a v0 model to v2, run `npx -y @archdoc/cli migrate blog.yaml -o .archdoc/archdoc.yaml`. It converts users to actors, components to elements, and dependencies to uses, and notes what to review. [Getting started](/docs/getting-started) covers the rest.
